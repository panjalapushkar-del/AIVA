# AIVA – AI Virtual Assistant

## About the Project
AIVA is an AI-powered virtual assistant developed using Python, Tkinter, and Google Gemini API. It provides intelligent responses to user queries, academic assistance, study planning, reminders, and an interactive chat interface.

## Features
- **AI Chat Assistant:** Get answers to academic and general questions using Google Gemini AI.
- **Academic Help:** Get assistance with learning topics and doubts.
- **Study Planner:** Generate study schedules.
- **Reminders:** Create reminders for important tasks.
- **Live Date & Time:** Displays the current date and time.
- **Chat Interface:** Interact with the AI through a simple graphical interface.

## Technologies Used
- Python
- Tkinter (GUI)
- Google Gemini API
- Google Gen AI Python SDK

## Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/panjalapushkar-del/Student-Virtual-Assistant.git
```

### 2. Open the Project Folder
```bash
cd Student-Virtual-Assistant
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Configure Gemini API Key

Generate an API key from Google AI Studio.

In Windows PowerShell, run:

```powershell
$env:GEMINI_API_KEY = "YOUR_API_KEY"
```

Replace `YOUR_API_KEY` with your actual API key.

**Important:** Never upload your API key to GitHub.

### 5. Run the Application
```bash
python main.py
```
