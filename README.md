# STUDY BUDDY - Student Virtual Assistant

## About the Project
Study Buddy is an AI-based Student Virtual Assistant
designed to help students with their academic activities.

## Objectives
- Answer academic questions.
- Help students create study schedules.
- Provide study reminders.
- Assist with exam preparation.
- Support student productivity.

## Technologies Used
- Python
- Artificial Intelligence
- Natural Language Processing
- Tkinter

## Features
1. Student Chat Assistant
2. Study Planner
3. Timetable Generator
4. Reminder System
5. Academic Support

## Project Type
Artificial Intelligence Lab Mini Project.
